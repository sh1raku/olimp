5. Где брать информацию

Подтверждено автором: RED OS 8.0.3 Standard; точные адреса и IPsec-данные — в карточке и топологии. Все необходимые облачные порты разрешены организатором. Версии и технологии свободные, проверяется функционал. Тестового доступа не планируется.

Как выполнять

  1. Заполните реальные данные в режиме 2. Примеры алгоритмов сверяйте с карточкой.
  2. Примените параметры и выполняйте команды по блокам.
  3. У защищённых сервисов проверьте обе стороны: локально доступен, с интернета закрыт.
  4. IPsec проверяйте отдельно. Его сбой не должен мешать доступу по существующей локальной сети.
  5. Сохраните HTML с прогрессом и проверьте автозапуск до перезагрузки жюри.

Условия / карточка стенда

Разбор ищет только standNN и зону. Топология и противоречивые адреса проверяются вручную; новые модули автоматически не создаются.

Параметры стенда

Пустые поля обязательны: заполните по реальной карточке. Автоматически подставляется только имя standNN, адреса не угадываются. PSK и пароли здесь не вводятся. Команды — шаблоны для выполнения по этапам, не единый установочный скрипт.
